# Certificate URL & LinkedIn Share Button

Odoo 19 module that adds a direct Certificate URL and a one-click
"Add to LinkedIn" button to Survey certifications, so participants can
share their passed certificates straight to their LinkedIn profile.

## Features

- Automatic Certificate URL for every passed certification
- One-click "Add to LinkedIn" button on the completion page
- Uses LinkedIn's official "Add to Profile" flow (pre-filled)
- Optional LinkedIn Company Page ID (Settings) for a verified organization link
- Certificate URL also visible on the backend participant record
- No changes to your certificate design or template

## Requirements

- Odoo 19.0
- Module: `survey` (with certification/scoring enabled)

## Configuration

No configuration needed. Optionally set your LinkedIn Company Page ID under
**Settings > General Settings > Certificate LinkedIn** for a verified
organization link. Leave it empty and it still works using your company name.
